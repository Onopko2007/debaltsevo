# Дебальцево — учебный многостраничный сайт

Автор: Онопко Николай Викторович, ДонГУ, группа ИВТ-6, 3 курс. Вариант 5.

## Запуск
Распакуйте архив целиком. Откройте debaltsevo/index.html в любом современном браузере. Установка библиотек и сборка не нужны. Не перемещайте HTML отдельно от style.css, script.js и assets.

Все фотографии, стили и скрипты локальные. Интернет нужен для встроенной карты и перехода к источникам. Сайт написан вручную, без конструктора, фреймворков и внешних JavaScript-библиотек.

## Страницы
- index.html — описание, новости и галерея из 6 фотографий.
- history.html — таблица из 13 исторических событий.
- infrastructure.html — география, OpenStreetMap в iframe, административное устройство, транспорт.
- culture.html — музей, культурные учреждения, выставки, сценическое творчество, Владимир Сосюра и свежая культурная новость.
- developer.html — фотография, сведения об авторе, горизонтальная диаграмма навыков.
- contact.html — форма с именем, email, темой и сообщением.

## Важные особенности
Новости проверены на 26 октября 2026 года. Новейшая включённая публикация — 26.10.2026, о работах 27.10.2026. Даты и ссылки на источники есть в карточках. Статический сайт обновляется вручную, а не автоматически. История города по смыслу содержит также события прошлых лет.

Фотографии города архивные, их даты и лицензии приведены в раскрывающемся блоке главной страницы. Они не выдаются за современные снимки.

Проценты навыков — демонстрационные значения самооценки (HTML 90%, CSS 80%, JavaScript 60%, Git 65%). Их следует скорректировать под реальные навыки автора: атрибут value у meter и текст процентов.

Форма использует required, type=email, minlength и maxlength, CSS-состояния валидности. JavaScript дополнительно проверяет строки из пробелов. Сервер отправки не подключён: форма честно сообщает, что сообщение не отправлено, и позволяет скачать его в UTF-8 .txt. Данные не хранятся и не отправляются в сеть. Для реальной доставки потребуется сервер или почтовый сервис.

В проверенных источниках не найдены подтверждённые действующие профессиональный театр, отдельная галерея и текущая афиша городского фестиваля. На странице культуры это указано; представлены подтверждённые культурные учреждения и выставочная деятельность.

## Соответствие CSS
- Позиционирование: static (.section), relative (.hero и .brand-icon), absolute (.hero-photo, .hero-shade, .photo-note), fixed (.back-top и .skip), sticky (.site-header).
- Обтекание: float:left у .float-image на странице истории, сброс float на мобильном экране, display:flow-root у родителя.
- Простые селекторы: универсальный *, тип body, класс .hero, идентификатор #form-status, атрибут [aria-current="page"], псевдокласс :hover. В терминологии CSS псевдоклассы входят в простые селекторы; формулировка задания про 6 видов учитывает именно эту классификацию.
- Комбинаторы: потомок (.site-header nav), ребёнок (.facts>div), сосед (.grid+.muted), последующие соседи (input~.form-actions).
- Более 10 псевдоклассов: :root, :lang, :link, :visited, :hover, :active, :focus, :focus-visible, :first-child, :last-child, :nth-child, :nth-of-type, :not, :disabled, :enabled, :required, :user-invalid, :user-valid, :empty.
- Псевдоэлементы: ::after (подчёркивание текущего раздела), ::before (индикатор проверки), ::selection; оформление полос meter.
- Адаптивность: Grid и Flexbox, медиазапросы на 1100 и 760 px, адаптивные размеры шрифтов, локальная прокрутка таблицы, мобильное меню на 2 строки. Учитывается prefers-reduced-motion.
